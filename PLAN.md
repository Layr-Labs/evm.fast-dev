# Plan / status

This repository is the development home of the challenge (`docs/CHALLENGE.md`): the original Pancake
source of the stateless guest (`guest/src`), its Lean AST and model (`Guest/`), and the checks that the
source passes the EEST corpus.

The guest was ported, milestone by milestone, in
[stateless-pancaketh](https://github.com/flamingoponderado/stateless-pancaketh); the milestone log (the
former contents of this file: precompile and accelerator work, ziskemu and software-guest history,
performance numbers) and the issues and pull requests live there.
